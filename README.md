# SteerQuant project website

Project page for **SteerQuant: Steering Quantization Error with Action-Guided Scaling in World-Action Models**.

- Paper: https://arxiv.org/abs/2609.39056
- Website: https://cathyyw.github.io/Steerquant-Website/

## Edit and preview

Edit `index.html`, `style.css`, or `script.js`. Figures are in `assets/` and are reproduced from the paper.

Run `python -m http.server 8000` in this directory, then open http://localhost:8000.

GitHub Pages publishes the root of the `main` branch. No build step or dependencies are required.
