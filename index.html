THE CENTRAL IDEA

Steer error where
it matters less.

Local quantization errors of the same size can have very different effects on robot actions.

SteerQuant redistributes quantization error, steering it away from computations with greater action impact and toward those with less influence on final actions.

01 / MAP

Where does error matter most?

Action-Impact Stream Map

Estimate how local quantization error in each layer–step–stream region changes the final action. Higher-impact regions receive greater importance during calibration.

WHY THIS MATTERS

Similar local errors can have very different effects on control.

02 / ROUTE

Steer error toward lower-impact regions.

Shared-Weight Error Routing

Route uses the Map to calibrate channel scaling and redistribute quantization error across semantic streams and denoising steps. It prioritizes reducing errors that strongly affect final actions, while tolerating more error where the impact is smaller.

THE ERROR TRADE-OFF

Less error where actions are sensitive; greater tolerance where they are less affected.

03 / MODULATE

Adapt activations. Keep weights.

Stream-Specific Activation Modulation

Refine stream-specific gains and a shared clipping threshold at each layer and denoising step. Store these parameters offline, then look them up during inference.

WHAT CHANGES — AND WHAT STAYS FIXED

Activation ranges adapt by stream and step. The quantized weights remain the same.

Step 1 of 3
CALIBRATE OFFLINE

Map → shared channel scaling → stream- and step-specific gains. Inference uses the fixed weights and calibrated lookup table.
